# اسکریپت‌های عملیاتی

اسکریپت‌های این پوشه باید تکرارپذیر، قابل لاگ‌گیری و امن باشند.

پیش از اضافه‌کردن اسکریپت Deploy یا Migration:

- اجرای دوباره آن نباید داده را خراب کند.
- ورودی‌ها اعتبارسنجی شوند.
- Secret در خروجی چاپ نشود.
- برای عملیات مخرب تأیید یا حالت Dry Run در نظر گرفته شود.
- Backup و Rollback مستند باشند.
